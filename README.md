## Overview

VUMT is a precision level meter combining a hardware-accurate VU ballistic meter with PPM, RMS, and LUFS-I measurements, calibration reference, and a configurable meter bridge layout.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Klanghelm VUMT** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **VU Ballistics** | Hardware-accurate 300ms integration VU ballistic response |
| **LUFS Metering** | Integrated loudness LUFS-I and LUFS-S display alongside VU |
| **Calibration** | Adjustable reference level from -18 to -14 dBFS for analog reference |
| **Meter Bridge** | Dual-meter layout with configurable metering type per channel |
